# Local broker reports for analysis

Use this directory for local copies of input reports during development.

Example paths:
- `local-samples/xtb/xtb-report-sample.xlsx`
- `local-samples/xtb/xtb-report-sample.csv`
- `local-samples/mbank/mbank-report-sample.xlsx`

Rules:
- This directory must be excluded from Git; verify `.gitignore`.
- Do not send these files to external services or models without informed approval and an appropriate privacy policy.
- Prefer anonymized or synthetic copies.
- Do not include these files in documentation, fixtures, or commits.
- The agent should describe the file structure without revealing sensitive values.
